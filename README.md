# Blast Radius Voice Studio

متن یا سناریویی که از کلاد می گیرید را بچسبانید؛ برنامه آن را به بخش ها و بلوک های «style + text» برای Gemini TTS تبدیل می کند و اگر بخواهید صدا را هم با گوینده **Enceladus** می سازد.

Paste a script from Claude, get TTS blocks with style and text, and make the audio with the Enceladus voice. One HTML file, no install.

## باز کردن

| کجا | چطور |
|---|---|
| همین کامپیوتر | روی `index.html` دوبار کلیک کنید (Chrome یا Edge). |
| کامپیوتر دیگر | پوشه یا فایل ZIP را کپی کنید، از حالت فشرده خارج کنید و `index.html` را باز کنید. |
| آنلاین (هر دستگاه، گوشی) | آدرس GitHub Pages را در مرورگر باز کنید. |
| گوشی، مثل یک اپ | Android (Chrome): منوی ⋮ ← **Add to Home screen**. iPhone (Safari): دکمه Share ← **Add to Home Screen**. |

## استفاده

1. **متن را بچسبانید.** یادداشت های `[VISUAL: …]`، برچسب های `{c12}`، تیترها و شماره پاراگراف ها خودکار حذف می شوند.
2. **نوع را انتخاب کنید** (یا Auto بماند): ویدیوی بلند به بخش های ۱ تا ۲ دقیقه ای تقسیم می شود؛ هر Short یک فایل است و جمله «The full story is on the channel.» به آخرش اضافه می شود.
3. **«آماده کن» را بزنید.** Gemini بلوک ها و styleهای کوتاه را می سازد. معمولا ۳ تا ۵ دقیقه طول می کشد؛ صفحه را نبندید. برنامه چک می کند هیچ کلمه ای عوض نشده باشد.
4. **اسکریپت آماده** را کپی کنید یا `.txt` بگیرید (همان قالب `tts.py`).
5. **صدا (اختیاری):** کلید API را یک بار وارد کنید، روی کامپیوتر «انتخاب پوشه» را بزنید، بعد «ساخت صدای همه بخش ها». فایل ها با نام نهایی (`1.wav`، `short2.wav`) ذخیره می شوند. روی گوشی هر فایل با دکمه Save دانلود می شود.

## لازم است

- **VPN روشن** (از ایران همه درخواست های Google API فقط با VPN کار می کنند).
- **کلید API** از [aistudio.google.com](https://aistudio.google.com) ← Get API key. کلید فقط در مرورگر همان دستگاه ذخیره می شود و هیچ جا فرستاده نمی شود جز خود گوگل. روی هر دستگاه یک بار باید وارد شود.
- مرورگر Chrome یا Edge (Safari و Firefox هم کار می کنند، ولی «انتخاب پوشه» فقط در Chrome و Edge کامپیوتر هست).

## صدای طبیعی تر

- **یک گوینده، نه بازیگر:** برنامه فقط از ۶ style ثابت استفاده می کند که همه با «calm» شروع می شوند. اگر خودتان style می نویسید، از همین فهرست بردارید. style های جورواجور (dramatic, weary, intriguing, …) لحن را مدام عوض می کنند.
- **بلوک کم:** ۲ تا ۴ بلوک در هر بخش. هر تعویض بلوک یعنی شروع دوباره لحن.
- **مکث کم:** فقط یک `<long pause>` بعد از سؤال از بیننده. بقیه ریتم را نقطه و ویرگول می سازند.
- **چند بار بسازید:** اگر بخشی خوب نشد، فقط همان را Regenerate کنید؛ هر بار کمی متفاوت خوانده می شود. بهترین را نگه دارید.
- **بعد از ساخت:** بلندی صدای همه فایل ها را یکسان کنید و مکث های بالای ۰٫۸ ثانیه را کوتاه کنید (در تدوین یا با Channel Studio).

## نکته ها

- اگر گوگل نام مدل را عوض کند و خطای 404 بیاید، نام جدید را در «تنظیمات مدل» بگذارید.
- صدا همیشه Enceladus است و عوض نمی شود.
- بعد از ساخت صدا گوش کنید: تگی بلند خوانده نشده باشد، صدا همه جا یکی باشد، اسم ها درست تلفظ شده باشند.
- روی کامپیوترهای مشترک کلید را در برنامه نگذارید، یا بعد از کار پاکش کنید (فیلد کلید را خالی کنید).
